# Chatie Editor Library

Production build v0.0.3-test - ESM only

## Installation

```bash
npm install git+https://github.com/EineBlume/chatie-editor-library-esm.git#v0.0.3-test
```

## Usage

```javascript
// Import components (ESM)
import { Editor, EditorManager } from '@chatie/editor-library';

// Import styles (if needed)
import '@chatie/editor-library/style.css';
```

## Package Info

- **Type**: ES Module (ESM) only
- **Main**: dist/editor.esm.js
- **Types**: dist/index.d.ts
- **Styles**: dist/editor.css

## Requirements

- Node.js project with ESM support (`"type": "module"` in package.json or `.mjs` files)
- Modern bundler (Vite, Webpack 5+, Rollup)
- React 16.8+ (Hooks support required) - supports React 16, 17, 18, 19+
