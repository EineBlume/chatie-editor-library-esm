# Chatie Editor Library

Production build v0.0.1

## Installation

```bash
npm install git+https://github.com/EineBlume/chatie-editor-library-esm.git
```

## Usage

```javascript
// ESM
import { Editor, EditorManager } from '@chatie/editor-library';

// CommonJS
const { Editor, EditorManager } = require('@chatie/editor-library');
```
